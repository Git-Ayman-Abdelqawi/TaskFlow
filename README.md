# TaskFlow – تبسيط الإنتاجية

## 📌 مقدمة
TaskFlow هو تطبيق مكتبي (Windows Forms) لإدارة المهام والإجازات، تم تطويره بلغة C# باستخدام Visual Studio.  
يهدف المشروع إلى مساعدة المستخدم على تنظيم وقته ومهامه اليومية من خلال واجهة رسومية سهلة الاستخدام ودعم اللغة العربية.

---

## 🚀 المميزات
- واجهة رسومية جذابة بخلفيات متدرجة.  
- إدارة حساب المستخدم (اسم، كلمة مرور، بريد إلكتروني، صورة شخصية).  
- إضافة مهام مع تحديد النوع، التاريخ، والصورة.  
- عرض المهام بشكل منظم داخل FlowLayoutPanel.  
- حساب أيام الإجازة وعدّ تنازلي للأيام المتبقية.  
- دعم اللغة العربية بشكل كامل.

---

## 🖥️ الشاشات
1. **Form1 (Task Flow):** الشاشة الرئيسية لعرض المهام والتحكم بها.  
2. **frmSwttings:** شاشة إعدادات المستخدم وتخصيص البيانات الشخصية.  
3. **frmAddTask:** شاشة إضافة مهمة جديدة مع خيارات التاريخ والنوع.  
4. **frmVacation:** شاشة حساب الإجازات وعدّ تنازلي للأيام المتبقية.

---

## ⚙️ طريقة التشغيل
1. افتح المشروع في برنامج Visual Studio.  
2. شغّل ملف الحل `TaskFlow.sln`.  
3. تأكد أن .NET Framework مثبت على جهازك.  
4. اضغط على زر التشغيل (Start) لتجربة التطبيق.
